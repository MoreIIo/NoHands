Excel ↔ Logiciel interne

Lit une valeur dans Excel, la recherche dans l'appli interne, et réécrit le résultat dans Excel.

Fichier Excel

Sélectionne tes cellules dans Excel Desktop ou Excel Web, copie (Ctrl+C), puis colle ci-dessous (Ctrl+V). La première ligne collée sert d'en-tête.

Choisis un fichier .json ou colle un JSON (tableau d'objets ou tableau de tableaux). Les clés du premier objet servent d'en-tête.

Mapping des colonnes

Donnez un nom à chaque colonne utile (ex: "nom" = colonne J).

Conditions (filtrage)

Ex: si colonne E = "NON" → ignorer la ligne.

Action sur le logiciel interne

Recherche

Ajoute un ou plusieurs champs si le logiciel interne a besoin de plusieurs valeurs pour chercher (ex: nom + prénom). Tous les champs sont remplis avant la validation.

Validation de la recherche

Résultats à récupérer

Chaque valeur trouvée sur la page est réécrite dans la colonne Excel indiquée : c'est l'aller-retour complet Excel → logiciel interne → Excel. Si les résultats sont dans un tableau sans id/name (plusieurs lignes identiques), choisis "Ligne de tableau (par valeur)" : ça cherche la ligne où une colonne correspond à la valeur voulue, puis récupère une autre colonne de cette même ligne.

Exécution

Laisse respirer le logiciel interne entre deux recherches (évite de le saturer ou de déclencher un anti-bot).
